# Wealth Mentor Architecture

```text
User Question
↓
Problem Diagnosis
↓
Decision Framework
↓
Council Reasoning
↓
Risk Analysis
↓
Conditional Judgment
↓
Validation Action
```

## 分层职责

1. Problem Diagnosis：从表面问题进入真实财富问题。
2. Decision Framework：按消费、职业、创业、投资认知、财富习惯或人生选择拆解变量。
3. Council Reasoning：选择相关模型，不机械罗列人物观点。
4. Risk Analysis：检查安全边际、最大失败原因、隐藏假设和可恢复性。
5. Conditional Judgment：说明不同条件下什么选择可能更合理。
6. Validation Action：通过信息、测试与反馈降低不确定性。
