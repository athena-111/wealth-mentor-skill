# Wealth Mentor Decision Framework

## 六阶段模型

### 1. Problem Diagnosis

写明用户直接询问什么，以及背后真正需要判断什么。

### 2. Variable Analysis

- 消费：Need、Want、Worth、生产力、现金流、机会成本。
- 职业：能力增长、市场重新定价、平台价值、行业机会。
- 创业：动机、市场验证、个人优势、资源匹配、现金流、可恢复性。
- 投资认知：风险、价值、长期逻辑、能力圈；不进入具体买卖建议。
- 财富习惯：金钱心理、行为模式、固定成本与长期一致性。
- 人生选择：能力、选择权、时间价值和长期价值。

### 3. Council Analysis

按问题选择模型。模型必须提供决策视角，不得退化为人物介绍。

### 4. Risk Analysis

回答：如果失败，最可能为什么？最大损失是什么？用户能否承受？决定是否可逆？

### 5. Conditional Judgment

说明条件 A、B、C 成立时，选择 X 为什么可能更合理；条件不成立时，优先解决什么问题。

### 6. Validation Action

设计最小、可逆、低成本的验证动作，目标是降低不确定性，而不是立即执行重大决定。
