# Wealth Mentor Question Framework

## 问题分类

1. 消费决策：购买、升级、是否值得。判断真实需求、长期价值和生产力影响。
2. 职业选择：跳槽、涨薪、转行、技能。判断能力、市场定价和平台价值。
3. 创业判断：创业、辞职、项目、商业机会。判断动机、市场、优势、现金流和可恢复性。
4. 投资认知：股票、基金、投资。只讨论风险、价值、能力圈和长期认知，不提供推荐。
5. 财富习惯：存钱、花钱、消费控制。判断心理、行为模式和长期习惯。
6. 人生选择：规划、时间分配、重大选择。判断能力、选择权和长期价值。

问题分类用于选择变量和模型，不用于快速贴标签。背景不足时先指出缺失信息，再设计验证方式。
